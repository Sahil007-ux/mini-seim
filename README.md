\# Mini-SIEM



Mini-SIEM is a lightweight Security Information and Event Management (SIEM) project built with Python. The goal is to learn how SIEM systems collect, process, analyze, and visualize security logs.



This project will start as a simple MVP and gradually add features such as log ingestion, event parsing, detection rules, alerts, and basic security monitoring.



\## Project Goals



\* Collect and process sample security logs

\* Detect suspicious or unusual activity

\* Generate security alerts

\* Build a simple foundation for a larger SIEM system

\* Learn practical concepts used in cybersecurity and SOC environments



> This project is being developed step by step as a learning and portfolio project.
